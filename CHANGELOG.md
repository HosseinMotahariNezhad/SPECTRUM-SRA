# Changelog

All notable changes to SPECTRUM SRA will be documented in this file.

## [1.0.0] — 2025-01-01

### Added
- Initial public release of the hosted application.
- PICO inclusion/exclusion criteria module.
- MeSH term extraction with parallel fetching.
- PDF-based keyword identification (uni-, bi-, tri-grams).
- Multi-group Boolean query builder (5 groups × 5 terms).
- Query translation for PubMed, Scopus, and Web of Science.
- PubMed and Scopus API search execution.
- Web of Science one-click launch.
- Retrieved Studies manager (upload, download, merge).
- DOI-based and fuzzy deduplication.
- Dual-reviewer title/abstract and full-text screening.
- Automatic Cohen's Kappa calculation.
- PRISMA 2020 flow diagram with high-resolution JPEG export.
- Search and screening textual reports.
- LLM-assisted data extraction prompts.
- Excel import/export with dropdown validation.
