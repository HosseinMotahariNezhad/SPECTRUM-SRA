# Contributing to SPECTRUM SRA

SPECTRUM SRA is a closed-source academic tool. However, we welcome:

- **Bug reports** — via [Issues](https://github.com/HosseinMotahariNezhad/SPECTRUM-SRA/issues)
- **Feature suggestions** — please describe the use case clearly
- **Documentation improvements** — typo fixes, clarifications
- **Scientific collaborations** — contact the authors directly

## Reporting Bugs

Include:
1. A clear, descriptive title.
2. Steps to reproduce.
3. Expected vs. actual behavior.
4. Screenshots if applicable.
5. Browser and operating system.

## Requesting Source Code Access

Email the authors (see README) with:
- Your name and affiliation.
- Intended use (research, teaching, or collaboration).
- A brief description of your project.

Requests are reviewed on a case-by-case basis.

## Code of Conduct

By participating, you agree to abide by our [Code of Conduct](CODE_OF_CONDUCT.md).
